# Changelog

## 1.0.2 — 2026-10-05

- Declare Certificate manager (`tool_certificate`) as a required parent plugin.
- Clarify installation, date-language behaviour and privacy documentation.
- Add the configuration screenshot to the public README.
- Date formatting and certificate output are unchanged.

## Licensing correction — 2026-08-24

- Restored the GNU GPL v3 or later license required by the GPL-licensed origin.
- Restored original copyright and author attribution and documented the adaptation.

## 1.0.0 — 2026-08-18

- Initial release of the `certificateelement_flexdate` subplugin.
- Adds standard and per-element custom Moodle strftime-style date formats.
- Supports the issue and expiry sources provided by the `tool_certificate` 4.5.7 date element.
- Adds an optional per-element date-language override chosen from installed site languages.
